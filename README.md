## Projetos Destaque

###  **Sistema de Bilhetagem VT** — Desktop AppSec
**Java Swing · SQLite · RBAC · BCrypt · Auditoria**

Aplicação desktop para controle de transporte com **4 papéis de usuário** (Operador, Gerente, Financeiro, Admin) e **rate limiting** contra força bruta.

<details>
<summary><b>Ver Detalhes</b></summary>

**Segurança Implementada:**
- Autenticação com BCrypt (nenhuma senha em plaintext)
- Controle de acesso baseado em papéis (RBAC)
- Logging de auditoria com rastreamento de integridade
- Rate limiting (máx 5 tentativas de login em 15 min)
- Expiração automática de sessão (15 min idle)

**Arquitetura:**
- Persistência em SQLite
- Geração de gráficos com JFreeChart
- Tratamento de concorrência com SwingWorker
- Design pattern: DAO + Service + UI

**Link:** [github.com/DouglasLira-Dev/sistema-bilhetagem-vt](https://github.com/DouglasLira-Dev/sistema-bilhetagem-vt)

</details>
