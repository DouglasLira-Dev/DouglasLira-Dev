### 🔐 [Sistema de Bilhetagem VT](https://github.com/DouglasLira-Dev/sistema-bilhetagem-vt)
> **Desktop app Java Swing com RBAC (4 papéis), auditoria e rate limiting — projeto principal de AppSec.**
* **Segurança Aplicada:** Controle de acesso baseado em papéis (RBAC), hashing de senhas com **BCrypt**, log de auditoria com integridade verificada e rate limiting contra tentativas de força bruta.
* **Arquitetura:** Persistência local em **SQLite**, geração de gráficos com **JFreeChart**, tratamento de concorrência com **SwingWorker** e expiração de sessão.
* **Stack:** `Java` `Swing` `SQLite` `BCrypt` `JFreeChart`

### 🛠️ [Stock Manager API](https://github.com/DouglasLira-Dev/stock-manager-api)
> **API REST para controle de inventário com autenticação e regras críticas de estoque.**
* **Segurança Aplicada:** Autenticação stateless com **JWT**, criptografia de senhas com **BCrypt** e controle de acesso via **Spring Security**.
* **Qualidade:** 20+ testes unitários automatizados com **JUnit 5 e Mockito**, 8 endpoints REST documentados via **Swagger** e monitoramento de integridade com **Spring Actuator**.
* **Stack:** `Java 17` `Spring Boot 3` `JWT` `SQLite/PostgreSQL`

### 🐍 [Compara Planilha](https://github.com/DouglasLira-Dev/compara-planilha)
> **App desktop em Python para comparação de planilhas funcionais por CPF.**
* **Problema Real Resolvido:** Cruza dados de duas planilhas (CPF, Matrícula, Data de Admissão) e gera relatório de divergências, com detecção automática de cabeçalho por palavras-chave.
* **Stack:** `Python` `PyQt6`
